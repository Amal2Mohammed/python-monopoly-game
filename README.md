# Python Monopoly Game 🎲

A Monopoly-style board game developed in Python using OOP concepts and game logic.

## Features
- Turn-based gameplay
- Dice rolling system
- Property purchasing
- Player balance management
- Jail system
- Win/Lose conditions

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Purpose
This project was created to practice Python programming, game logic, and software design concepts.
